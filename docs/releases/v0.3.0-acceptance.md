## Windows installed-app acceptance

named by the v0.3.0 manifest. An earlier package exposed three real defects: task
editing attempted to clone Vue proxies, the native shortcut did not reach the
frontend, and uninstall left the product registry key. Those defects were fixed
and the candidate was rebuilt. A later review-session evidence fix required one
more rebuild; that final candidate passed all six automated smoke stages and its
bounded installed-app rerun recorded 16 `PASS`, zero `FAIL`, and six explicit
`NOT_RUN` checks.
The installed-app run isolated the existing Roaming and Local product folders,
used synthetic task data, then uninstalled the app and restored the original
folders. The original `study.db` was restored at 196608 bytes with SHA-256
`c6ef465c30fd98ca5c5cad30b94b07ef23f6803d613f8ade74c014e928af3fdf`.
