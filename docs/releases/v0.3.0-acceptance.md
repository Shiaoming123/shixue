Updated: 2026-09-08 (Asia/Shanghai)

PR #25 merged the release guard, legacy WorkspaceState v3 compatibility repair,
and corrected Windows package-smoke data boundary into `main`. The public
`v0.3.0` release was built from tag target `ccad25b` by release workflow run
`34103463012`; its test, configuration, provenance, build, upload, asset
verification, and publication stages all passed.

smoke report incorrectly treated child `APPDATA` and `LOCALAPPDATA` overrides as
Tauri data isolation even though Tauri loaded the real Windows Known Folder
database.

Status meanings:

- `PASS`: the listed command or observation completed against the stated source
  or exact artifact bytes.
- `FAIL`: the command ran but its acceptance condition did not pass.
- `NOT_RUN`: the listed manual or native observation has not been performed.
- `BLOCKED`: an external identity, environment, device, or reputation result is
  unavailable.
