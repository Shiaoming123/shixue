# v0.3.0 Acceptance Ledger

Updated: 2026-09-07 (Asia/Shanghai)

This ledger records evidence for the v0.3.0 release implementation before its
release PR is merged. The branch is based on `893c9bb` and adds the release
workflow guard, legacy WorkspaceState v3 compatibility repair, and corrected
Windows package-smoke data boundary. The final candidate identity is the exact
`main` commit after this PR merges. No `v0.3.0` tag or GitHub Release exists.

The earlier Windows artifacts built from `893c9bb` are superseded because they
do not contain the compatibility repair. Their hashes and the former six-stage
smoke report are historical evidence only. That smoke proved installation,
process liveness, uninstall, and bounded installer cleanup, but its claimed
`APPDATA`/`LOCALAPPDATA` isolation was false: Tauri used Windows Known Folders
and loaded the existing product database.

Status meanings:

- `PASS`: the listed command or observation completed against the current
  source worktree.
- `FAIL`: the command ran but its acceptance condition did not pass.
- `NOT_RUN`: no result exists for the final merged candidate.
- `BLOCKED`: required external identity, environment, device, or reputation
  evidence is unavailable.
