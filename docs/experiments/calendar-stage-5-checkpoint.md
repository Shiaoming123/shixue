# 阶段5：建议安排、专注与周复盘

日期：2026-09-09。阶段5本地实现与代表性浏览器验收完成。没有发送外部日历写入。

## 实现与边界

- 未安排任务可查找单个连续时段；用户明确采用才经 `task.auto_schedule` 保存。使用预计时长、截止时间、工作时间、已有任务/事件和有效忙闲缓存，候选按15分钟对齐，不移动其他任务。
- 预览绑定 Workspace/Task revision 与 availability fingerprint；采用时重新计算。陈旧版本、已过期忙闲、未知外部覆盖都拒绝写入。正常时钟跳动不清空预览，候选过时才失效。
- 循环任务只读展开用于冲突判断；超过可证明的展开范围/数量上限时返回 unknown。没有完整覆盖证明的有限系列可能保守拒绝建议，不把未知当空闲。
- 缺预计时长、容量不足、截止已过、外部忙闲未知均有原因；本次未排入原因只存于本次使用，不制造持久业务日志。
- 采用复用任务 reschedule/undo，现有 Focus 复用真实 StudySession；周复盘分别显示计划、真实专注、完成与真实移动事件。跨周累计专注无法精确分配时单独报告，不伪造时段。
- Task 与 Event 在日历中使用同一显示时区；UTC/显式 offset 的相同瞬间显示一致，菜单、拖动、键盘及未安排入口均按显示时区构造目标。
- 修复桌面回顾入口的数组下标假设；日期范围复用紧凑 DateTimePicker，避免窄弹层两个月历重叠。
