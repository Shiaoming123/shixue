## 五点对照

1. **结构**：当前工作区采用七项桌面主导航（收件箱、今天、最近 7 天、日历、清单、已完成、学习）、中央任务表和宽屏行内详情；紧凑视口收敛为单列内容与五项底部导航（收件箱、今天、日历、清单、学习），最近 7 天与已完成经“清单/更多”可达。
2. **色彩**：两者都使用暖纸色背景、深墨正文和低饱和鼠尾草绿作为唯一强调色；状态差异主要靠图标、文案与极少量警示色表达。
3. **层级**：页面标题、快速捕捉、状态筛选、任务行、详情证据链逐层展开，默认列表不暴露过多技术字段。
4. **控件质感**：实现保留细边框、轻阴影、圆角分组、半透明移动导航、底部 Sheet 和至少 44px 的移动触控目标。
5. **密度与响应式**：1280px 起同屏保留列表和 360px 行内详情；820–1279px 使用图标侧栏与 360px 覆盖详情，819px 以下把详情放入带 grabber 的响应式 Sheet，且页面不产生横向滚动。

## 数据与文案变化

- 日期由系统本地时间生成，不固定为概念图日期。
- 概念图使用产品设计阶段的示例任务；实现截图使用可重复恢复的 LangGraph 演示数据。
- 实现把“完成标准”与可勾选的“执行检查项”分开，防止勾选子项绕过证据式完成。
- 完成一次学习后，记录库保留标题快照、收获、证据与下一步；“从下一步建任务”是显式动作。

## 有意保留的偏差

- Web 截图不伪造 iOS 状态栏和 Home Indicator；这些只存在于移动概念图，仍需原生真机验证。
- 字体使用系统字体栈优先匹配 Apple 字体，但没有随应用分发 SF Pro 字体文件。
- 实现比概念图多一个“已取消”筛选，以完整呈现状态机；移动端因此使用可滚动筛选条。
- 概念图展示收件箱任务，确定性实现截图展示已完成/已计划任务，用来同时验证重开与开始入口。

## 已验证交互

- 收件箱 3 秒捕捉，刷新后任务仍存在。
- 整理任务时补充主题、计划日期、预计时长与完成标准。
- 开始 → 暂停 → 刷新后自动恢复专注页、计时状态和随手记。
- 收获、成果证据、下一步缺一不可；成功完成后可在记录库全文检索。
- 桌面行内详情、中等视口覆盖详情、紧凑视口响应式 Sheet 与五项底部导航均可操作。
- 自动化检查期间浏览器控制台与页面异常均为零。

浏览器交互先在应用内浏览器完成；固定视口截图和完整持久化闭环由同一 Web 构建通过 Playwright + Edge 生成，并再次交给本地图片检查器逐张核对。
